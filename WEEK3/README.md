# Historia de usuario semana 3

Implementacion de componentes reutilizables para el sistema de usuarios.

## Encarpetado

```plaintext
src/
├── components/
│   ├── Badge.tsx
│   ├── Button.tsx
│   └── Card.tsx
├── interfaces/
│   ├── Badge.ts
│   ├── Button.ts
│   └── Card.ts
├── App.tsx
├── index.css
└── main.tsx
```

## Instalacion

```bash
npm install
```


## Ejecución

```bash
npm run dev
```


## Componentes Disponibles

1. Boton determinar el color y la estética del botón, así como su tamaño.
2. Badge muestra el estado del componente.
3. Card muestra el estado del componente.

## Descripción y Tecnologías

Vite, React, TypeScript, CSS


## Notas 

Historia de usuario enfocada en la reutilizacion de componentes y la creacion de interfaces reutilizables.
