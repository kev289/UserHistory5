# Ecommerce Lite

Proyecto de React con TypeScript para renderizar listas dinámicas de productos y usuarios utilizando componentes reutilizables y tipado estricto.

## Estructura del Proyecto
- `/src/components`: Componentes visuales (Cards).
- `/src/interfaces`: Contratos de datos y tipado estricto (TypeScript).
- `/src/data`: Información mockeada que el sistema usa.

## Instrucciones de ejecución

1. Abre tu terminal en la carpeta principal del proyecto.
2. Asegúrate de tener instaladas las dependencias ejecutando:
   `npm install`
3. Inicia el servidor de desarrollo en tu computadora ejecutando:
   `npm run dev` (o `npm start` dependiendo del entorno).
4. Abre la dirección generada en tu navegador (usualmente http://localhost:5173).
